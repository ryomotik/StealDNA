# 🧬 Steal DNA Hub / Украсть ДНК — Roblox Script

Многофункциональный скрипт-хаб для игры **«Украсть ДНК» (Steal DNA)** в Roblox с современным интерфейсом **WindUI**.

## ⚡ Быстрый запуск (Loadstring)

Вставьте эту строку в ваш Roblox-экзекутор:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/ryomotik/StealDNA/main/StealDNAScript.lua"))()
```

---

## 🚀 Возможности

### 1. 🏃 Фарм и Тренировка скорости
- **Авто-тренировка (Auto Train):** Автоматически встает на беговую дорожку и запускает бег.
- **Супер-клик буст (5x Combo):** Спамит пакеты `TrainClick` с интервалом 0.07 с, непрерывно удерживая максимальный 5-й уровень комбо для мгновенного набора скорости.
- **Авто-прокачка дорожки ($):** Покупает апгрейд беговой дорожки за внутриигровой кэш.

### 2. 🧬 Кража ДНК (Auto-Steal)
- **41 вид животных:** Все животные от Медведя до Меха-Титана отсортированы по требуемой скорости.
- **Мгновенная кража ДНК:** Телепорт к спящему животному -> мгновенное срабатывание `StealPrompt` -> автоматический возврат за безопасную линию (`SafeLine`), исключая риск быть пойманным.
- **Циклический авто-фарм (Auto Steal Loop):** Автоматическая кража ДНК выбранного животного по кулдауну.

### 3. 🔬 База и Инкубаторы
- **Авто-сбор мутантов (Claim All):** Автоматически проверяет все 5 слотов мутатора и забирает созревших мутантов.
- **Авто-прокачка участка (Plot Upgrade):** Расширение базы за кэш.
- **Авто-прокачка инкубатора (Mutator Upgrade):** Ускорение времени скрещивания.

### 4. 📍 Телепорты
- Мгновенный телепорт на свою базу (Plot).
- Телепорты по всем биомам карты (Лес, Озеро, Пустыня, Джунгли, Снег, Вулкан, Бездна, Доисторический, Смерть, Радуга).

### 5. 👁️ ESP Животных
- Подсветка спящих животных через стены:
  - 🟩 **Зелёный:** скорости персонажа хватает для кражи.
  - 🟥 **Красный:** скорости недостаточно (показывает требуемую скорость и расстояние).

### 6. ⚡ Модификаторы персонажа
- Регулировка `WalkSpeed` и `JumpPower`.
- Бесконечный прыжок (`Infinite Jump`).
- Проход сквозь препятствия и капканы (`Noclip`).
- Чистая выгрузка скрипта (`Unload`).
